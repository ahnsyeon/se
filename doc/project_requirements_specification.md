## 1. 개요

### 1.1 문서의 목적 및 범위

본 문서는 AI 기반 상황 인식 무음 커뮤니케이션 지원 시스템(SilentTalk)에서 각 요구사항이 무엇인지 조사하고 정의하는 문서이다. 본 문서는 기능적, 비기능적, 인터페이스에 요구되는 사항들을 정의한다.

요구사항은 다음의 원칙에 따라 작성한다.

- 요구사항은 기능적 요구사항, 비기능적 요구사항, 인터페이스 요구사항으로 구분하여 작성한다.
- 품질 요구사항은 프로젝트에서 식별한 품질 요소를 기준으로 정의한다.
- 개발 요구사항에는 개발 지원 소프트웨어, 하드웨어 요구사항 등을 포함한다.
- 요구사항을 정의할 때는 반드시 요구사항 작성법을 준수한다.

### 1.2 프로젝트 개요

#### 1.2.1 프로젝트 정의

본 시스템은 청각장애인 및 난청 사용자를 대상으로, 카메라 기반 상황 인식과 AI를 활용하여 의사소통을 지원하는 서비스이다. 사용자의 현재 위치 및 환경을 분석하여 상황에 적합한 문장을 자동으로 추천하고, 버튼 기반 인터페이스를 통해 빠르게 의사표현을 할 수 있도록 한다.

#### 1.2.2 주요 기능 설명

| ID | 기능명 | 설명 |
|----|--------|------|
| F01 | 상황/장소 인식 | 카메라 입력을 통해 카페, 병원, 학교 등 환경 자동 인식 (Computer Vision) |
| F02 | 버튼 기반 의사 표현 | 타이핑 없이 버튼 선택으로 즉시 의사 전달 지원 |
| F03 | AI 기반 대화 흐름 추천 | 대화 맥락을 분석하여 다음 문장 자동 추천 |
| F04 | 상황 맞춤 문장 생성 | 장소 + 상황에 맞는 자연스러운 문장 생성 (NLP) |
| F05 | 제스처 기반 입력 | 손동작으로 문장 선택 및 UI 조작 (Computer Vision) |
| F06 | 사용자 맞춤 학습 | 자주 사용하는 문장을 학습하여 우선 추천 |

### 1.3 관련 문서, 용어 및 약어

#### 1.3.1 참조 문서

#### 1.3.2 용어 정의

| 용어 | 설명 |
|------|------|
| Computer Vision (CV) | 카메라 등 이미지/영상 입력으로부터 시각적 정보를 인식·분석하는 AI 기술 |
| NLP | 자연어 처리 (Natural Language Processing). 텍스트를 이해하고 생성하는 AI 기술 |
| AAC | 보완대체의사소통 (Augmentative and Alternative Communication). 언어 장애인을 위한 의사소통 지원 기술 |
| TTS | 텍스트 음성 변환 (Text-to-Speech). 텍스트를 음성으로 출력하는 기술 |
| 버튼 기반 인터페이스 | 타이핑 없이 미리 정의된 버튼을 선택하여 의사를 표현하는 UI 방식 |
| 상황 인식 | 카메라 입력으로 현재 장소 및 환경(카페, 병원 등)을 자동으로 파악하는 기능 |
| 온디바이스 처리 | 서버 전송 없이 기기 내부에서 AI 연산을 수행하는 방식 |

### 2.2 비기능적 요구사항

#### 2.2.1 성능 요구사항

| 분류 | 요구사항 | 우선순위 |
|------|----------|---------|
| NFR-001 | 시스템은 상황 인식(장소 분류) 결과를 카메라 입력 후 온디바이스 처리 기준 1초 이내에 출력한다. 단, 클라우드 API 연동 시에는 네트워크 왕복 시간(RTT)을 포함하여 3초 이내를 목표로 하며, 응답 지연이 발생할 경우 로딩 인디케이터를 표시한다. | 상 |
| NFR-002 | 시스템은 버튼 선택 후 UI 반응(화면 전환 및 텍스트 출력)을 300ms 이내에 완료한다. 외부 API 호출이 수반되는 경우에는 1.5초 이내를 허용하며, 처리 중임을 나타내는 피드백을 즉시 제공한다. | 상 |
| NFR-003 | 시스템은 외부 NLP API(OpenAI 등) 연동 시 API 응답 타임아웃을 5초로 설정하며, 타임아웃 발생 시 캐시된 추천 문장 또는 기본 문장 목록을 대체 제공한다. 정상 네트워크 환경(LTE 이상)에서의 전체 응답 시간은 3초 이내를 목표로 한다. | 상 |
| NFR-004 | AI 문장 추천은 대화 맥락 변경 후 2초 이내에 갱신된다. 단, 외부 API 처리 환경에 따라 최대 4초까지 허용하며, 갱신 지연 시 이전 추천 목록을 유지하고 갱신 완료 후 화면을 업데이트한다. | 상 |
| NFR-005 | 시스템은 동시 접속 사용자 100명 기준으로 API 평균 응답 시간이 3초를 초과하지 않아야 하며, 최대 허용 응답 시간(P95)은 5초 이내로 관리한다. | 상 |
