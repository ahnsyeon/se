## 1. 서론

### 1.1 문서 목적 및 범위

본 문서의 목적은 충북대학교 소프트웨어학과의 프로젝트 과목 '캡스톤 디자인'을 위해 진행하는 'AI 기반 상황 인식 무음 커뮤니케이션 지원 시스템(SilentTalk)' 프로젝트에 대한 테스팅을 수행하고 그 결과를 나타내는 데에 있다. 본 문서에서는 위 프로젝트의 테스트 기준, 테스트 범위, 테스트 케이스와 테스트 결과를 명시한다.

### 1.2 프로젝트 개요

SilentTalk는 청각·언어 장애 사용자를 대상으로, 카메라 입력을 통해 현재 상황과 장소를 인식하고 그에 맞는 추천 문장을 버튼 형태로 제공하여, 타이핑 없이도 빠르게 의사를 전달할 수 있도록 지원하는 모바일 시스템이다. 사용자 계정 관리, 상황 인식 기반 문장 추천, 대화 흐름 추천, 제스처 기반 UI 조작, 즐겨찾기 및 학습 데이터 관리 기능을 포함한다.

### 1.3 용어 정의

| 용어 | 설명 |
|---|---|
| 서버사이드 | 서버 측 시스템을 뜻하며, 본 프로젝트에서는 데이터베이스, 자연어 처리 및 학습 기능 등을 수행한다. |
| 클라이언트 | 사용자 눈에 보이는 시스템을 뜻하며, 본 프로젝트에서는 모바일(Android/iOS) 앱을 뜻한다. |
| CV 모델 | 카메라 입력을 분석하여 현재 장소(카페, 병원, 학교 등)를 분류하는 컴퓨터 비전 모델을 뜻한다. |
| NLP API | 자연어 문장 생성 및 대화 흐름 추천을 위한 외부 자연어 처리 API를 뜻한다. |

## 2. 테스트 개요

### 2.1 테스트 범위

테스트는 시스템 내부를 모른다는 가정 하에 블랙박스 테스트로 이루어진다. 테스트의 범위는 아래와 같다.

| 범위 | 내용 |
|---|---|
| Mobile 기반 시스템 | Ⅰ. 클라이언트/서버사이드 동작 정확성 확인<br>Ⅱ. 요구사항 충족 확인 |
| 상황 인식 모듈 | Ⅰ. 카메라 입력 기반 장소 인식 정확성 확인<br>Ⅱ. 인식 결과 갱신 속도 확인 |
| Database | Ⅰ. 사용자/학습 데이터 입출력 시험<br>Ⅱ. 사용자별 데이터 독립성 확인 |

### 2.2 테스트 항목 및 통과 기준

#### 기능별 테스트 항목 통과 기준

| 기능별 테스트 항목 | 통과 기준 |
|---|---|
| 회원가입 기능 | 이메일/비밀번호가 정확한 형식이며 중복되지 않은 정보만이 가입에 성공한다. |
| 로그인 기능 | 올바른 회원정보만이 로그인에 성공한다. |
| 상황 인식 기능 | 카메라 입력을 통해 현재 장소를 인식하고 1초 이내에 결과를 반영한다. |
| 문장 추천 및 출력 기능 | 인식된 상황에 맞는 문장 목록을 제공하고, 버튼 선택 시 1초 이내에 문장을 출력한다. |
| 대화 흐름 추천 기능 | 이전 대화 맥락을 바탕으로 다음 문장을 추천하고, 맥락 변경 시 추천 목록을 갱신한다. |
| 제스처 조작 기능 | 정의된 제스처 입력에 따라 UI가 정확히 반응한다. |
| 즐겨찾기 기능 | 사용자가 등록한 문장을 즐겨찾기에 추가/삭제할 수 있다. |
| 학습 데이터 관리 기능 | 사용자별 학습 데이터가 독립적으로 저장되며, 초기화/삭제가 가능하다. |

#### 비기능별 테스트 항목 통과 기준

| 비기능별 테스트 항목 | 통과 기준 |
|---|---|
| 기기 호환 테스트 | Android 10 이상 및 iOS 14 이상 기기에서 시스템이 정상적으로 작동한다. |
| 오프라인 동작 테스트 | 네트워크 미연결 환경에서도 기본 버튼 기반 의사 표현 기능이 동작한다. |
| 응답 시간 테스트 | 상황 인식 1초, 버튼 반응 300ms, 문장 추천 갱신 2초 이내 기준을 충족한다. |
| 보안 테스트 | 로그인하지 않은 사용자가 시스템의 핵심 기능을 이용할 수 없다. |

## 3. 테스트 케이스

### 3.1 테스트 케이스 선정

테스트 케이스는 본문 2.2의 기능별/비기능별 테스트 항목에 따라 선정하였으며, 블랙박스 테스트 기법을 기반으로 하여 시스템 내부 확인을 하지 않는 사용자 시점 테스트 케이스 선정에 중점을 둔다. 본문 3.3에서 기능별 테스트 케이스 목록을 나열한다.

### 3.2 테스트 케이스 유형

테스트 케이스 유형은 다음과 같다.

- 입력 기능을 수행하기 위한 문자열/이미지 입력 테스트 케이스
- 카메라 입력 기반 상황 인식 동작 확인을 위한 인식 테스트 케이스
- 추천 문장 출력 및 응답 속도 확인을 위한 동작 테스트 케이스
- 사용자별 데이터 독립성 확인을 위한 데이터 입력 및 확인 테스트 케이스
